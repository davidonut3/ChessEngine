In this document, I will teach you how to build your own chess bot. We will discuss how to represent a chess position, how to calculate the legal moves in a given position, and how to determine which move is the best option. To achieve optimal results, we will give up some simplicity for efficiency.

I will be using \texttt{C\#} syntax for the code snippets, but I will not use any language specific functionalities. Which language you use is up to you, but I recommend a fast, compiled language, like \texttt{C\#}, \texttt{C/C++} or \texttt{Rust}. Personally, I used Rust for the backend, and Python for the UI.
