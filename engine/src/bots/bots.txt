bot n-1: GrandmasterEngine:

Best bot possible with:
- somewhat limited time
- no thinking while opponent is playing
- single thread search
- modest amount of memory

bot n: FinalEngine:

Best bot possible with:
- generous time limit
- thinking continuously
- multi thread search
- lots of memory

Notes: There are a lot of parameters that we choose somewhat arbitrarily, so we will use the following greedy algorithm to find the best parameters:
First, we make a guess for each parameter, and implement all the ideas above with those parameters. Then, when we have a strong bot,
we check many values for each parameter to see which is the best. We then combine the best results in our chess bot.
